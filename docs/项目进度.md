### 代码块修复记录（2026-09-12）

- 问题根因是 Hexo 在启用 `highlight.js` 时，将 fenced code block 预处理为 `<hexoPostRenderCodeBlock>`，随后转换为内部 HTML 注释占位符；`hexo-renderer-marked` 的 DOMPurify 会安全地移除该注释，导致 Hexo 无法恢复代码内容。
- 关闭 Hexo 的预处理高亮后，Marked 原生输出标准的 `<pre><code class="language-bash">` HTML，DOMPurify 可安全保留它。没有关闭 `dompurify`，因此文章 HTML、事件属性和危险链接仍会被净化。
- `test/code-block-rendering.test.js` 会先执行 `hexo clean` 再实际构建，并断言文章产物包含 fenced 代码内容；这样不会因 `db.json` 缓存误判通过。本次已运行并通过该测试、完整 `npm test`、`npm run check` 与 `npm run build`。
- 当前主题会显示标准代码块，但不再提供服务端 `highlight.js` 的语法着色、行号和代码标题；日常文章请统一使用 fenced Markdown，不要使用 `{% codeblock %}` 等 Hexo 标签插件。
