# 沉浸式工作台首页实施计划

> **面向执行代理：** 实施时按任务顺序执行，每个任务完成后运行该任务列出的测试；不得提交或推送 Git，除非用户另行要求。

**目标：** 将 Hexo 主题升级为参考站风格的沉浸式博客工作台：首页拥有全屏自然首屏和居中内容，滚动后进入侧栏与主内容分栏；全站增加动态网点背景、可读性面板和液态玻璃返回顶部交互。

**架构：** 保留现有 EJS + Stylus 主题结构。新增一个站点级 UI 部分负责动态背景、返回顶部按钮和首页液态玻璃调参面板；新增可复用的 EJS 侧栏部分，由页面模板传入文章集合后自动生成统计、最近更新、标签和分类。首页在首屏后使用工作台网格，文章页使用同一侧栏与正文面板。

**技术栈：** Hexo EJS、Stylus、原生 JavaScript、Canvas 2D（动态网点）、CSS `backdrop-filter` 降级液态玻璃、Node `node:test`、JSDOM、现有 Hexo 构建命令。不添加远端 CDN 或运行时依赖。

## 全局约束

- 所有新增或修改的 Markdown 文档使用中文。
- 使用已审核的自然山湖首屏图和用户提供的猫咪头像，不复制参考站图片、文字或后端。
- 不覆盖或回退工作区中已有的用户修改，不改动 CMS、OAuth、部署配置和文章内容。
- 动态效果遵守 `prefers-reduced-motion`；低性能或无 Canvas 时必须有静态/CSS 降级。
- 代码块继续保留 Atom One Dark、语言名、行号、复制、折叠和移动端横向滚动。
- 不自动提交或推送 Git。

- 设计文档中的全屏首屏、透明导航、精选文章顺序、侧栏、动态网点、阅读面板、返回顶部按钮、调参面板、移动端布局和减少动态效果均有对应任务。

- 测试任务先于实现任务，所有新增接口均在任务中定义，未使用 `TBD`、`TODO` 或未定义的函数名。
