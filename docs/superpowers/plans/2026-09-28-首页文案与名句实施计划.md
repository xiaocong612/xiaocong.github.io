# 首页文案与名句实施计划

> 执行方式：使用 executing-plans 在当前会话逐项执行，遵循 test-driven-development，按用户要求不启动子代理。

**目标：** 实现已确认的居中首页、打字与名句交互、后台句库、渐隐及悬停过渡。

**架构：** EJS 独立首页组件消费 Hexo 数据，单独的首页脚本从转义后的 DOM 读取句库。现有 Stylus 负责布局和渐变，Decap 文件集合写回 YAML。

**技术栈：** Hexo、EJS、Stylus、原生浏览器脚本、Decap、Node 测试、JSDOM。

## 全局约束

- 保留工作区全部已有修改、图片及文章侧栏，不提交、不推送。
- Markdown 使用中文；不写入密钥，不调用外部名句接口。
- 首页保持至少 100svh，字体使用固定断点，不使用视口字号缩放。
