# 玻璃组件与网点视觉实施计划

**目标：** 完成黑透圆角面板、蓝色悬停边缘、150/72 点网、圆形置顶按钮和真实液态玻璃集成。

**架构：** 主题 EJS/Stylus 保持现有结构；网点和滚动行为仍在 `site-ui.js`；第三方渲染器、shader 和 Leva 控件以独立 Vite 入口构建，主题仅挂载入口与按钮容器。

**技术栈：** Hexo、Stylus、Canvas 2D、WebGL2/WebGPU、React、Leva、Vite、Node 测试。

## 约束

- 文档均用中文。保留工作区已有改动，不提交或推送。
- 第三方原始许可与来源随源码保存，不仿写上游 shader 或参数控件。
- 测试先于实现，完成后运行全量测试、站点检查、构建和浏览器检查。
