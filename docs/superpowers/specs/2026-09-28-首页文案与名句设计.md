# 首页文案与名句设计

本方案已经用户确认，直接在当前工作区继续，不覆盖已有主题改动，不提交或推送。

## 页面效果

- 保留已选山湖图片和满屏首屏。图片与暗色遮罩底部约 220px 渐隐，露出全站背景和网点；不淡化文字或滚动提示。
- 文字居中，依次为站点名称、小标题、较大的循环文案、磨砂玻璃名句框。底部保留向下阅读入口。
- 文案逐字打出、停留、逐字删除，再切换下一句。用全部完整文案预留高度，避免下面的名句框跳动。
- 名句显示正文、可选作者，右侧图标按钮随机换一句，不重复当前句子，切换时淡出淡入。
- 已有蓝色高亮面板的边框、光晕约 0.3 秒渐亮、渐暗，不改变文章侧栏布局。

## 内容管理

`source/_data/home.yml` 保存 `subtitle`、`phrases: [{text}]`、`quotes: [{text, author}]`。Decap 新增「首页内容」，两类列表支持增删、编辑与排序。名称仍来自站点设置。

发布沿用现有 GitHub 和 Hexo 构建链路。后台保存草稿不会立即更新线上页面，发布并完成部署后生效。不引入外部名句服务，不修改 OAuth。

## 降级与安全

- EJS 转义所有内容，前端仅用 `textContent`；不拼接可执行脚本。
- 空列表回退到默认中文内容；单条名句禁用切换。
- 不执行脚本时首句、名句仍可阅读，隐藏无功能按钮。
- 减少动效时显示静态文案，名句手动即时切换。隐藏标签页或首屏移出视口时暂停打字。
- 手机文字可换行，按钮大小固定；不新增远端运行时依赖。
