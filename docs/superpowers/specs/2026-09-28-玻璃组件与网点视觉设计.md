# 玻璃组件与网点视觉设计

## 目标

在现有 Hexo 主题上完成首页和内页视觉调整。首页最近更新区域改为圆角黑色半透明面板；主要卡片和阅读面板统一黑色半透明底色，悬停或键盘焦点进入时边缘呈蓝色高亮。全站网点背景桌面约 150 点、手机约 72 点，近邻连线清晰可见但不过度遮挡内容。

## 交互与布局

- 最近更新外框采用 24px 圆角和内容裁切，不再出现直角大矩形。
- 精选文章、最近更新、侧栏 profile/统计/widget、阅读与列表面板使用黑色半透明背景；文本使用浅色，次要文本有足够对比度。
- 上述板块的边框在鼠标进入和 `:focus-within` 时变蓝，并出现克制的蓝色外发光。高亮不改变框的尺寸。
- 返回顶部按钮保持 48px 正圆、右侧滑入/滑出和箭头上下交换。短页面和页面顶部不显示。
- 网点每帧只连接有限近邻，点和线有低幅呼吸。新点先缓显，寿命末段缓消，连线透明度跟随端点过渡；减少动效时绘制静态图。

## 液态玻璃来源

使用 `iyinchao/liquid-glass-studio` 的 MIT 授权源码。保留原项目 WebGL2/WebGPU 多 Pass 渲染器、GLSL/WGSL shader、Leva 参数控件和中文标签；新增博客集成入口仅负责确定按钮画布尺寸、位置、默认值和快捷键。实际折射所需背景使用原项目的纹理输入接口，不能声称浏览器可以直接对任意 DOM 做实时折射。若图形能力不可用，显示明确的简化按钮和错误状态。

## 范围

只修改主题 UI、对应测试、第三方源码与许可记录，不改文章、CMS、OAuth 和部署配置。现有用户修改保留，不自动提交或推送。验证桌面、手机、文章页与首页快捷键。
