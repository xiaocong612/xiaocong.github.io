# 沉浸式博客首页设计

## 目标

调整博客首页的前端呈现，使其在视觉层次和滚动体验上参考 `https://chortle.asia/`：首屏先完整展示主视觉，继续向下滚动后再进入精选文章与博客内容。仅参考前端布局和交互，不复制对方的图片、文案、品牌元素或后端功能。

## 已确认的设计

- **首屏主视觉：** 使用已审核的原创自然山湖图片，铺满首屏视口。桌面端和移动端均以视口高度为基准，兼容 `100svh` 与 `100vh`；图片覆盖裁切，不拉伸。
- **文字布局：** 网站名称、简介和主要行动入口在首屏中央对齐，确保背景对比度足够。首屏不展示精选文章标题或文章卡片。
- **导航：** 首页首屏中透明叠加在主视觉上；离开首屏后切换为带半透明背景与模糊效果的吸顶导航。内页继续使用清晰可读的常规导航样式。
- **滚动引导：** 首屏底部提供可点击的向下提示，目标指向精选文章区域。支持键盘焦点和辅助技术名称。
- **内容顺序：** 主视觉之后依次展示精选文章、最近更新文章流和站点页脚。精选文章继续链接到真实文章；归档、关于、搜索入口保持可用。
- **主页工作台：** 首屏之后进入左右分栏工作台，左侧为完整侧栏，右侧依次为欢迎栏、快捷入口、精选文章、分类导航和最近更新文章流。
- **动效：** 图片轻微缓慢缩放、首屏文字入场、精选区域进入视口时渐显。动效克制，不影响阅读；遵守 `prefers-reduced-motion`，开启减少动态效果时关闭非必要动画和滚动平滑。
- **视觉方向：** 保留 Apple 风格的简洁排版和自然色彩，同时吸收参考站的沉浸式全屏主视觉、清晰内容分段与滚动叙事。不使用参考站的专有图片或素材。
- **全站动态背景：** 所有页面共享轻量网点背景层。点随机生成、消失和缓慢漂移，只有部分近邻点随机连线，点与线以低幅度透明度呼吸；限制点数、连线距离和刷新频率，避免干扰阅读。开启减少动态效果时停用持续动画并保留低密度静态背景。
- **内容可读性面板：** 文章正文使用半透明灰色微高斯模糊面板、细边框和轻阴影承载内容。代码块继续使用深色 Atom One Dark 风格，与正文面板保持明确对比。
- **侧栏工作台：** 桌面端在首页和文章等可滚动内容页使用左侧 sticky 侧栏，包含猫咪头像、站点简介、文章/标签/分类统计、最近更新、标签和分类 widget；数据从 Hexo 当前站点数据生成。移动端将完整侧栏移动到主内容前面并纵向排列。
- **液态玻璃返回顶部：** 所有实际可滚动页面提供液态玻璃风格返回顶部按钮。按钮在页面顶部或页面高度不足一屏时隐藏，向下滚动后从右侧滑入，回到顶部时向右侧滑出；悬停/聚焦时箭头上下交换。首页额外提供 `Shift + T` 调参面板，参数仅保存在当前会话，并在 WebGL/WebGPU 不可用时降级为 CSS 毛玻璃。

## 实现边界

- 只改造 Hexo 主题的首页布局、首页导航状态、相关样式和必要的首页脚本/构建测试。
- 优先沿用当前首页原创自然背景、精选文章数据和最近更新列表，不引入新的运行时依赖或远端 CDN。
- 导航滚动状态只在首页启用；文章、归档、分类、标签、搜索和关于页面的布局与导航功能不应退化。
- 不改动 CMS、OAuth、部署配置或文章内容。
- 同一工作区中已有未提交修改，实施时需保留并基于现状增量修改。

## 交互与响应式要求

- 首屏高度至少覆盖可视视口；在初始页面位置，精选文章区域不应提前露出。
- 点击滚动提示或主行动按钮可平滑到达精选文章区域；减少动态效果设置下改为即时滚动。
- 小屏下标题和简介仍居中且完整可读，按钮可换行/纵向排列，导航可用，不产生横向溢出。
- 图片提供准确的中文替代文本；装饰性遮罩不进入无障碍树。
- 图片和文字叠加区域需有足够遮罩对比度，浅色或深色模式下均保持可读。
- 动态网点位于内容下层，文章面板和侧栏面板具有足够不透明度/模糊度，正文不受网点连线穿透影响。
- 所有页面在内容高度不足一屏时不渲染返回顶部按钮；按钮支持鼠标、键盘焦点和触摸操作。

## 验收标准

1. 构建后的首页主视觉高度覆盖桌面和手机视口，精选文章在其后出现。
2. 首页顶栏初始透明叠加；滚动离开主视觉后出现半透明模糊底色，并保持吸顶。
3. 中央标题、简介、按钮在桌面与手机上不重叠、不溢出。
4. 向下提示能跳转到精选文章；精选文章和最近更新仍链接到正确内容。
5. 非首页的导航行为、文章页代码块功能及其他页面不回归。
6. 首页和文章页均有侧栏工作台；移动端侧栏完整纵向显示且不产生横向溢出。
7. 可滚动页面的返回顶部按钮按滚动位置滑入/滑出，悬停箭头完成上下交换。
8. `Shift + T` 只在首页切换液态玻璃调参面板，WebGL/WebGPU 不可用时仍可使用 CSS 降级效果。
9. `npm test`、`npm run check`、`npm run build` 与 `git diff --check` 全部通过。
10. 在本地浏览器实际验证桌面和手机首页首屏、滚动后的精选区、侧栏、网点背景、返回顶部按钮，以及文章页代码高亮和阅读面板。

## 验证方式

- 构建测试断言生成后的首页包含全屏主视觉、滚动提示、精选文章目标锚点和滚动状态所需的结构/样式。
- 使用本地预览在桌面与手机视口检查首屏是否完整、精选内容是否只在滚动后出现、导航状态是否切换，以及小屏是否无横向溢出。
- 打开一篇包含代码块的文章，确认语法颜色、行号、复制与折叠操作仍可用。
- 在首页和文章页滚动到中段，确认网点动画/静态降级、侧栏布局和返回顶部按钮行为；回到顶部后确认按钮滑出。
