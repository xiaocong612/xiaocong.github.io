你好，我是小聪。

这是我的个人记录空间，主要写三类内容：技术实践中的解决方案、学习过程中的阶段性总结，以及生活里值得保留的片段。我希望每篇文章都能留下清晰的上下文，也能在未来重新帮到自己。

## 这个博客怎么更新

文章源文件保存在 `source/_posts`，可以用熟悉的 Markdown 编辑器直接写作。完成后先运行本地检查，再提交到 GitHub；网站会由 GitHub Actions 自动生成并发布。

你也可以从导航栏进入 `/admin/`，使用 Decap CMS 在浏览器里编辑文章和图片。两种方式写入的是同一套 Markdown 文件，适合不同场景下快速更新。

## 内容分类

- **技术**：工程实践、工具配置与可复用的解决方案。
- **学习**：阅读、课程和长期积累中的理解。
- **随笔**：生活观察、想法和不定期记录。

感谢你的阅读，欢迎通过文章中的链接与我交流。
